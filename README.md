# Animax 🎬

Animax is a full-stack **anime discovery web application** built using a MERN-style architecture.
The platform allows users to browse, search, and explore anime with a modern UI inspired by popular anime platforms.

---

## 🚀 Features

* Browse anime from a large anime database
* Search anime by title
* View detailed anime information
* Discover trending anime
* Discover top anime
* Infinite scrolling for anime browsing
* Featured anime hero section
* Trailer support for selected anime

---

## 🛠 Tech Stack

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* Axios
* CORS
* dotenv

### Frontend

* React
* React Router
* Axios
* CSS

---

## 🌐 API Source

Anime data is fetched from the **Jikan API**, which provides anime information from MyAnimeList.

## ⚙️ Installation

### Clone the repository

```
git clone https://github.com/hellomresh/animaxx.git
```

### Install backend dependencies

```
npm install
```

### Install frontend dependencies

```
cd animax-frontend
npm install
```

---

## ▶️ Run the Project

Start backend:

```
npm run dev
```

Start frontend:

```
cd animax-frontend
npm start
```
